# Earth texture attribution

- `blue-marble-february-4096.jpg` is a web-optimized derivative of NASA
  Earth Observatory's **Blue Marble: Next Generation — February** global
  base map (5400 × 2700 source image).
- `blue-marble-surface-4096.jpg` is a high-quality 4096 × 2048 derivative
  of NASA Earth Observatory's lossless 8192 × 4096 **Land Surface, Ocean
  Color and Sea Ice** texture. This is the active cloud-free day surface.
- `black-marble-4096.jpg` is a web-optimized derivative of NASA Earth
  Observatory's **Earth at Night / Black Marble** global map.
- `blue-marble-clouds-4096.jpg` is a 4096 × 2048 web derivative of NASA
  Goddard SVS **Equirectangular Projected Earth for LARGEST**. It combines
  Blue Marble land/ocean data with a CPC cloud composite for a photographic
  orbital daytime surface.
- `clouds-2048.jpg` is NASA Earth Observatory's global **Blue Marble:
  Clouds** composite. It is used as a separate data layer so the cloud deck
  can receive independent sunlight and atmospheric depth.
