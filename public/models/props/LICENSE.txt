Third-party 3D assets used in this scene
=========================================

The scene now commits to a single visual family: Kenney's flat-shaded
low-poly CC0 aesthetic. Every downloaded GLB below ships under CC0
1.0 Universal (public domain, no attribution required).

kenney/ (Kenney "Nature Kit")
  Source  : https://kenney.nl/assets/nature-kit
  License : CC0 1.0 Universal
  Files   : tree_oak, tree_fat, plant_bushDetailed, plant_bushLarge,
            flower_yellowA, flower_purpleA, flower_redA, mushroom_red,
            mushroom_tanGroup, campfire_stones, rock_largeA, log_stack
  Usage   : Hub, Gallery, Experience, Contact organic detail.

kenney/ (Kenney "Space Kit")
  Source  : https://kenney.nl/assets/space-kit
  License : CC0 1.0 Universal
  Files   : satelliteDish_detailed, astronautA, craft_speederA, meteor_detailed
  Usage   : satelliteDish_detailed — Skills hero centerpiece (floating,
            rotating — replaces the retired DamagedHelmet PBR hero).
            astronautA — Hub easter egg beside the mascot (replaces the
            retired Khronos Duck).
            craft_speederA — ambient flyer orbiting the scene (replaces
            the retired three.js Parrot).
            meteor_detailed — preloaded; reserved for future decor.

kenney/ (Kenney "Mini-Arcade")
  Source  : https://kenney.nl/assets/mini-arcade
  License : CC0 1.0 Universal
  Files   : arcade-machine, pinball
  Usage   : Flanking props on the Projects island — "retro tech exhibit"
            framing for the three project plinths.

robot-expressive.glb
  Source  : three.js examples — RobotExpressive
  URL     : https://github.com/mrdoob/three.js/blob/master/examples/models/gltf/RobotExpressive/
  License : MIT (three.js repo)
  Notes   : The mascot. 13 rigged animation clips used across the gesture
            palette. Kept for its clips; closely matches the Kenney toy
            aesthetic.

Retired assets (removed this polish pass for art-direction consistency):
  - DamagedHelmet (Khronos, CC BY-NC) — PBR photorealism clashed with
    the low-poly family. Replaced by satelliteDish_detailed.
  - Duck (Khronos, CC BY) — toy stylisation didn't belong. Replaced
    by astronautA.
  - Parrot (three.js) — orphaned style. Replaced by craft_speederA.

Attribution surfaced in the site footer (`src/ui/Footer.tsx`).
